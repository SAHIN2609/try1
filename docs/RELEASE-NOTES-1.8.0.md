# SISHHIN HZ MACHINE 1.8.0 — ABYSS Guitar AutoTune

## AutoTune

The plugin now includes a scale-aware guitar pitch-correction processor integrated before the amp/synth chain. It uses the existing stable monophonic guitar pitch tracker plus a short crossfaded pitch shifter.

### Scale maps

- Major
- Natural Minor
- Dorian
- Mixolydian
- Phrygian
- Phrygian Dominant

Every scale is available in all 12 chromatic keys.

### Controls

- Lock On/Off
- Key
- Scale
- Speed
- Amount
- Humanize
- Mix
- Tracking

The UI includes a live note/frequency display, target note frequency, cents meter and forged ABYSS tuning wheel.

## Factory presets

The bank now contains 158 presets, including ten AutoTune-focused presets covering the major/minor/modal scale families. The six dedicated synth presets remain unchanged.

## Important

AutoTune is intentionally optimized for monophonic guitar material. It is not a polyphonic chord-level pitch correction engine.
