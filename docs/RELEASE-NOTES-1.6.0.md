# SISHHIN HZ MACHINE 1.6.0 — ABYSS Full Surface Remodel

The supplied ABYSS emblem is now the visual identity of the entire interface, not only the amp hero.

## UI
- Integrated the emblem into the top brand mark, global background watermark, navigation signature strip, amp grille, amp control panel, synth/cab/EQ cards, page watermarks and footer.
- Reworked the interface into a unified black-steel / silver / violet hardware language.
- Tightened borders, bevels, shadows, metal highlights and glass depth so the controls read as one premium piece of hardware.
- Preserved the normal native preset selector for reliable WebView interaction.
- Responsive behavior remains enabled.

## Amp
- The supplied emblem is visually embedded into the grille rather than presented as a separate floating logo.
- Added a subtle emblem glow and metal/grille treatment.
- Reworked chassis, panel and handle proportions.

## Build
- Project version: 1.6.0.
- The existing Windows VST3 GitHub Actions build remains in place.
