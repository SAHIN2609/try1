# SISHHIN HZ MACHINE 1.7.0 — ABYSS FORGED UI

## Fixes
- Fixed the synth ON/OFF control by restoring the complete synth parameter table to the WebView state bridge.
- Synth toggle now has an explicit ON/OFF state, `aria-pressed`, hover text, and bypass visual state.
- Preset loading and A/B snapshots now include all synth parameters because the WebView state table contains the full parameter set.

## UI redesign
- Reworked the interface as a forged-metal hardware surface rather than a logo placed over a panel.
- Added an embossed/engraved version of the supplied ABYSS emblem.
- Integrated the engraving into the amp grille, front-panel badge, and card surfaces.
- Added machined-metal highlights, inset shadows, screw/plate treatment, darker chassis geometry, and physical-looking control surfaces.
- Synth, cabinet, EQ, navigation, preset browser, and footer now share the same ABYSS hardware language.
